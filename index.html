0. 준비09:20–09:50 · 30분

STEP 0-1

Claude 기본 사용 익히기

🎯 AI가 처음이라도 '묻기 → 파일 올리기 → 결과 받기' 한 바퀴를 해 봅니다.
  1. claude.ai에서 ＋ 새 채팅
  2. 입력창에 '안녕, 오늘 인허가 서류 실습을 해' 입력 → 보내기
  3. 입력창의 ＋(파일 첨부)로 서식 1개 올리고 '이 파일 제목만 알려줘' 보내기
  4. '이 내용을 엑셀 파일로 만들어줘' 보내기 → 파일 카드의 다운로드
엑셀 파일이 내 PC에 내려받아지면 오늘 실습 준비 끝입니다.
파일 카드가 안 나오고 글로만 답하면 설정의 '코드 실행 및 파일 생성' 기능이 꺼져 있는 것입니다. 강사에게 알려주세요.
💻 CLI 수강생 같은 준비를 마친 뒤 바로 1단계로 가도 됩니다. 원하면 Claude Code 등 CLI 도구로 같은 작업을 해 봐도 좋습니다(선택).
STEP 0-2

실습 파일 확인

🎯 오늘 쓸 서식 6개와 예비 파일을 내 PC에 둡니다.
  1. 홈의 실습 파일 zip 내려받기 → 압축 풀기
  2. forms 폴더에 서식 6개가 있는지 확인
  3. 파일 이름 끝이 .hwpx인지 확인
A_1 ~ A_6 서식 6개가 모두 .hwpx로 보입니다.
확장자가 안 보이면 탐색기 [보기] → [파일 확장명]을 켭니다.
STEP 0-3

HWP를 HWPX로 바꾸기 (실제 서식일 때)

🎯 관공서에서 받은 .hwp 서식을 AI가 다룰 수 있는 .hwpx로 저장합니다. 5단계에서 다시 씁니다.
  1. 한글에서 서식을 열고 메뉴 파일
  2. 다른 이름으로 저장하기
  3. 파일 형식에서 한글 표준 문서(*.hwpx) 선택 (버전에 따라 'HWPX 문서')
  4. 저장
같은 이름의 .hwpx 파일이 하나 더 생깁니다.
PDF로만 받은 서식은 한글로 열면 표가 깨질 수 있습니다. 가능하면 기관 누리집에서 HWP 서식을 받으세요.
STEP 0-4

Claude 프로젝트 만들고 서식 올리기

🎯 서식을 한 번만 올려 두고 여러 채팅에서 함께 씁니다(사용량도 아낍니다).
  1. claude.ai 왼쪽 프로젝트
  2. ＋ 새 프로젝트 (화면에 따라 '프로젝트 만들기') → 이름 예: 인허가서류_실습
  3. 프로젝트 화면 오른쪽 파일(또는 '프로젝트 지식')의 ＋ → 서식 6개 올리기
프로젝트 파일 목록에 서식 6개가 보입니다.
파일 올리기가 안 되면 새로고침 후 한 개씩 올려 봅니다.
💻 실습은 PC에서 서식 편집·생성 실습은 PC(한글 설치)에서 합니다. 휴대폰은 화면 확인·복습용으로 보세요. 그림은 탭하면 크게 볼 수 있습니다.

STEP 1-1

서식 1장 → 입력 항목표 (첫 성공)

🎯 서식에 어떤 값이 어디에 몇 번 들어가는지 표로 봅니다.
  1. 프로젝트에서 새 채팅 열기
  2. 아래 프롬프트 복사 → 입력창에 Ctrl+V
  3. 보내기 ↑
  4. 답변 표에서 '없음'·[확인필요] 칸 확인
첨부한 [A_1_전기사업허가신청서] 서식에서 입력 항목을 뽑아 표로 정리해줘. - 열: 항목명 | 현재 값 | 위치(쪽, 표/본문/서명란) - 서식에 없는 값은 지어내지 말고 '없음'으로 - 날짜는 YYYY-MM-DD, 설비용량은 kW 숫자로 - 같은 값이 여러 곳에 나오면 위치를 모두 적어줘
왜 쪽 번호까지 묻나요? 값이 틀렸을 때 원문 어디를 보면 되는지 바로 찾기 위해서입니다.
항목명·현재 값·위치가 표로 나오고, 신청일이 머리부와 서명란 두 곳에 있다는 것이 보입니다.
표 대신 긴 글로 답하면 '표로만 다시'라고 한 줄 보냅니다. 파일을 못 읽는다고 하면 0-4에서 파일이 올라갔는지 확인합니다.
STEP 1-2

6종 공통 항목 매핑표 받기

🎯 서류마다 이름이 다른 같은 항목을 '표준 키' 하나로 묶습니다.
  1. 새 채팅에서 아래 프롬프트 복사·붙여넣기
  2. 보내기
  3. 답변에서 '사업 위치·위치·소재지…'가 한 키로 묶였는지 확인
프로젝트에 있는 서식 6개를 모두 읽고, 서류마다 반복되는 입력 항목을 '표준 키' 하나로 묶은 매핑표를 만들어줘. - 열: 표준 키 | 현재 값 | 서류별 항목명(A1~A6) | 형식 - 같은 값이라도 뜻이 다르면(예정일과 실제 완료일) 다른 키로 나눠줘 - 접수번호·제출일·수신처처럼 서류마다 다른 값은 따로 표시 - 표 밖의 본문 문장·서명란에 들어간 값도 빠짐없이 - 서류끼리 날짜가 앞뒤가 안 맞는 곳이 있으면 [확인필요]로 알려줘
💻 CLI 수강생 매핑 결과를 예비 스크립트 make_templates.py의 LABEL_KEY(항목명 → 키 표)와 비교해 보세요. 어긋나는 항목이 있으면 이유를 적어 둡니다.
표준 키 약 20개 안팎의 표가 나오고, A2 개발행위허가 신청일이 전기사업 허가일보다 빠르다는 [확인필요]가 보이면 성공입니다.
서류 6개 중 일부만 읽었다면 '6개 모두 읽었는지 서류별로 확인해줘'라고 보냅니다.
여기까지 배운 것 같은 값이 서식마다 다른 이름으로, 표·본문·서명란 여러 곳에 반복된다는 것. 이것이 휴먼에러가 생기는 자리입니다.
💻 실습은 PC에서 서식 편집·생성 실습은 PC(한글 설치)에서 합니다. 휴대폰은 화면 확인·복습용으로 보세요. 그림은 탭하면 크게 볼 수 있습니다.

master.xlsx가 내려받아지고, [프로젝트] 시트에 키·값·형식·쓰이는 서류 열이 있습니다.
모양이 예시와 조금 달라도 괜찮습니다. 키 열과 값 열만 있으면 됩니다. 두 번 시도해도 어긋나면 실습 파일의 master.xlsx를 씁니다.

def templatize_value(label: str, text: str) -> str:
    """표의 값 칸: 항목명으로 키를 정해 치환."""
    if label == "공사 기간":  # 날짜 2개가 한 칸에 → 순서로 의미를 구분
        dates = re.findall(DATE, text)
        if len(dates) == 2:
            return text.replace(dates[0], "{{공사시작일}}", 1).replace(dates[1], "{{준공예정일}}", 1)
        if len(dates) == 1:
            return text.replace(dates[0], "{{준공예정일}}", 1)
        return text
    key = LABEL_KEY.get(label)
    if not key:
        return text
    if key in SAMPLE and SAMPLE[key] in text:
        return text.replace(SAMPLE[key], "{{%s}}" % key)
    if re.fullmatch(DATE, text.strip()):
        return "{{%s}}" % key
    return text


def templatize_text(text: str) -> str:
    """머리부·서명란·본문 문장."""
    text = re.sub(r"접수번호: \S+", "접수번호: {{접수번호}}", text)
    text = re.sub(r"(신청일|신고일): " + DATE, r"\1: {{제출일}}", text)
    if re.fullmatch(DATE, text.strip()):  # 서명란 위 날짜 한 줄
        return "{{제출일}}"
    for r in RECIPIENTS:
        text = text.replace(r, "{{수신처}}")
    for key in GENERIC:
        text = text.replace(SAMPLE[key], "{{%s}}" % key)
    return text


def templatize_xml(xml: str) -> str:
    labels = set(LABEL_KEY) | {"공사 기간"}
    prev = {"t": None}

    def sub(m):
        raw = html.unescape(m.group(1))
        new = templatize_value(prev["t"], raw) if prev["t"] in labels else raw
        new = templatize_text(new)
        prev["t"] = raw
        return "<hp:t>%s</hp:t>" % html.escape(new, quote=False)

    return re.sub(r"<hp:t>(.*?)</hp:t>", sub, xml, flags=re.S)


def leftovers(xml: str) -> list[str]:
    """치환되지 않고 남은 예시 값 목록 (비어 있어야 정상)."""
    texts = " ".join(html.unescape(t) for t in re.findall(r"<hp:t>(.*?)</hp:t>", xml, flags=re.S))
    found = [v for v in list(SAMPLE.values()) + RECIPIENTS if v in texts and v not in ("태양광",)]
    found += re.findall(DATE, texts)
    return found


def rewrite_zip(src: Path, dst: Path, new_section: str):
    """mimetype 을 첫 항목·무압축으로 유지해야 한글이 정상 인식한다."""
    with zipfile.ZipFile(src) as zin, zipfile.ZipFile(dst, "w") as zout:
        for info in zin.infolist():
            data = zin.read(info.filename)
            if info.filename == "Contents/section0.xml":
                data = new_section.encode("utf-8")
            comp = zipfile.ZIP_STORED if info.filename == "mimetype" else zipfile.ZIP_DEFLATED
            zout.writestr(info, data, compress_type=comp)


def main(src_dir: str, out_dir: str):
    out = Path(out_dir)
    out.mkdir(parents=True, exist_ok=True)
    bad = 0
    for f in sorted(Path(src_dir).glob("*.hwp[xt]")):
        with zipfile.ZipFile(f) as z:
            xml = z.read("Contents/section0.xml").decode("utf-8")
        new = templatize_xml(xml)
        left = leftovers(new)
        keys = sorted(set(re.findall(r"\{\{(.+?)\}\}", new)))
        name = re.sub(r"_P\d{4}-\d{2}", "", f.stem) + "_템플릿.hwpx"
        rewrite_zip(f, out / name, new)
        print(f"{name}: 키 {len(keys)}개 {keys}")
        if left:
            bad += 1
            print(f"  ⚠ 남은 예시 값: {left}")
    if bad:
        sys.exit(f"치환 누락이 있는 서식 {bad}개 — 위 ⚠ 를 확인하세요")


if __name__ == "__main__":
    main(sys.argv[1], sys.argv[2])

"""fill_forms.py — 마스터 시트(xlsx) 한 장으로 인허가 서류(hwpx) 여러 개를 한 번에 채운다.

구조
  master.xlsx [프로젝트] 키·값  +  [서류별] 접수번호·제출일·수신처
        │  읽기 → 형식 맞추기(날짜 YYYY-MM-DD, kW·㎡ 숫자)
        ▼
  1) 사전 검증: 빈 값·날짜 형식·날짜 선후        → 문제는 [검증리포트]에 기록 (생성은 계속)
  2) 템플릿 {{키}} 치환 → out/*.hwpx 저장        → 빈 값은 [확인필요]
  3) 사후 검증: 생성 파일을 다시 열어 {{ }} 잔여·값 반영 여부 대조
  * 미리보기(PrvText/PrvImage)에 남은 옛 값을 지운다 — 파일 탐색기 미리보기로 옛 고객 정보가 새는 것 방지

사용: python3 fill_forms.py master.xlsx <템플릿폴더> <출력폴더> [--strip-lineseg]
  --strip-lineseg : 한글에서 글자가 겹쳐 보일 때만 사용(줄 배치 캐시 삭제, 한글이 다시 계산하도록 하는 용도 — 효과는 실물 확인 필요)
"""
import datetime as dt
import html
import io
import re
import sys
import zipfile
from pathlib import Path

from openpyxl import load_workbook

MISSING = "[확인필요]"
DATE_KEYS = {"허가일", "공사시작일", "준공예정일", "공사완료일", "사용전검사확인일", "사업개시일", "제출일"}
PERMIT_DOCS = {"A2", "A3", "A4", "A5", "A6"}  # 전기사업 허가번호를 적는 서류


def fmt(key, v):
    """엑셀 값 → 서류에 들어갈 글자."""
    if v is None or str(v).strip() == "":
        return None
    if isinstance(v, (dt.datetime, dt.date)):  # 엑셀이 날짜로 바꿔 버린 경우도 받아 준다
        return v.strftime("%Y-%m-%d")
    if key == "설비용량":
        n = float(str(v).replace(",", "").replace("kW", "").strip())
        return f"{n:,.3f}".rstrip("0").rstrip(".")  # 998.4 / 1,000 / 99.75
    if key == "부지면적":
        n = float(str(v).replace(",", "").replace("㎡", "").strip())
        return f"{n:,.2f}".rstrip("0").rstrip(".")  # 12,500
    return str(v).strip()


def read_master(path):
    wb = load_workbook(path, data_only=True)
    proj, raw = {}, {}
    for k, v, *_ in wb["프로젝트"].iter_rows(min_row=2, values_only=True):
        if k:
            raw[k] = v
    docs = []
    for row in wb["서류별"].iter_rows(min_row=2, values_only=True):
        if row[0]:
            docs.append(dict(zip(["id", "name", "template", "접수번호", "제출일", "수신처"], row)))
    return raw, docs


def check(proj, docs):
    """사전 검증 — 사람이 자주 틀리는 것들."""
    msgs = []
    for k, v in proj.items():
        if v is None:
            msgs.append(f"[빈 값] 프로젝트.{k}")
        elif k in DATE_KEYS and not re.fullmatch(r"\d{4}-\d{2}-\d{2}", v):
            msgs.append(f"[날짜 형식] 프로젝트.{k} = {v} (YYYY-MM-DD 로)")

    def d(s):
        try:
            return dt.date.fromisoformat(s)
        except (TypeError, ValueError):
            return None

    order = [("공사시작일", "준공예정일"), ("공사시작일", "공사완료일"), ("공사완료일", "사용전검사확인일"),
             ("사용전검사확인일", "사업개시일")]
    for a, b in order:
        if d(proj.get(a)) and d(proj.get(b)) and d(proj[a]) > d(proj[b]):
            msgs.append(f"[날짜 순서] {a}({proj[a]}) 가 {b}({proj[b]}) 보다 늦음")
    for doc in docs:
        sub = d(doc["제출일"])
        if doc["id"] in PERMIT_DOCS and sub and d(proj.get("허가일")) and sub < d(proj["허가일"]):
            msgs.append(f"[날짜 순서] {doc['id']} {doc['name']} 제출일({doc['제출일']})이 전기사업 허가일({proj['허가일']})보다 빠른데 "
                        f"허가번호를 적게 되어 있음 → 확인필요")
    try:
        kw = float(proj["설비용량"].replace(",", ""))
        if kw <= 3000:
            msgs.append(f"[참고] 설비용량 {proj['설비용량']} kW ≤ 3,000 kW → 발전사업허가 신청처는 시·도지사 "
                        f"(전기사업법 시행규칙 제4조, 위임 조례는 지자체 확인) — A1 수신처 확인")
    except (KeyError, AttributeError, ValueError):
        msgs.append("[빈 값/형식] 설비용량은 kW 숫자만")
    return msgs


def fill_xml(xml, values, strip_lineseg):
    used = set()

    def put(m):
        k = m.group(1)
        used.add(k)
        return values.get(k) or MISSING  # 빈 값은 지어내지 않고 [확인필요]

    def sub_t(m):  # <hp:t> 안의 글자만 바꾼다 (태그 구조는 그대로)
        text = re.sub(r"\{\{(.+?)\}\}", put, html.unescape(m.group(1)))
        return "<hp:t>" + html.escape(text, quote=False) + "</hp:t>"  # & < > 이스케이프

    out = re.sub(r"<hp:t>(.*?)</hp:t>", sub_t, xml, flags=re.S)
    if strip_lineseg:
        out = re.sub(r"<hp:linesegarray>.*?</hp:linesegarray>", "", out, flags=re.S)
    return out, used


def plain_text(xml):
    return "\r\n".join(html.unescape(t) for t in re.findall(r"<hp:t>(.*?)</hp:t>", xml, flags=re.S))


def blank_png(png_bytes):
    """미리보기 그림을 같은 크기의 흰 이미지로 (옛 값이 그림으로 남는 것 방지)."""
    try:
        from PIL import Image
        w, h = Image.open(io.BytesIO(png_bytes)).size
        buf = io.BytesIO()
        Image.new("RGB", (w, h), "white").save(buf, "PNG")
        return buf.getvalue()
    except Exception:  # PIL 이 없으면 원본 유지 — 리포트에 남김
        return None


def write_hwpx(src, dst, new_xml, notes):
    with zipfile.ZipFile(src) as zin, zipfile.ZipFile(dst, "w") as zout:
        for info in zin.infolist():
            data = zin.read(info.filename)
            if info.filename == "Contents/section0.xml":
                data = new_xml.encode("utf-8")
            elif info.filename == "Preview/PrvText.txt":
                data = plain_text(new_xml).encode("utf-8")
            elif info.filename == "Preview/PrvImage.png":
                b = blank_png(data)
                if b is None:
                    notes.append(f"[주의] {dst.name}: 미리보기 그림을 지우지 못함(PIL 없음)")
                data = b or data
            comp = zipfile.ZIP_STORED if info.filename == "mimetype" else zipfile.ZIP_DEFLATED
            zout.writestr(info, data, compress_type=comp)  # mimetype 첫 항목·무압축 유지


def verify(dst, values, used):
    """사후 검증: 생성 파일을 다시 열어 대조."""
    with zipfile.ZipFile(dst) as z:
        text = plain_text(z.read("Contents/section0.xml").decode("utf-8"))
    errs = []
    if "{{" in text:
        errs.append(f"[치환 누락] {dst.name}: {set(re.findall(r'{{(.+?)}}', text))}")
    for k in sorted(used):
        v = values.get(k)
        if v and v not in text:
            errs.append(f"[반영 안 됨] {dst.name}: {k}={v}")
    blanks = sorted(k for k in used if not values.get(k))
    return errs, blanks


def main():
    args = [a for a in sys.argv[1:] if not a.startswith("--")]
    strip = "--strip-lineseg" in sys.argv
    master, tdir, odir = Path(args[0]), Path(args[1]), Path(args[2])
    odir.mkdir(parents=True, exist_ok=True)
    raw, docs = read_master(master)
    proj = {k: fmt(k, v) for k, v in raw.items()}
    for doc in docs:
        doc["제출일"] = fmt("제출일", doc["제출일"])
    report = ["# 검증 리포트", f"생성 시각: {dt.datetime.now():%Y-%m-%d %H:%M}", "", "## 1. 사전 검증"]
    report += check(proj, docs) or ["문제 없음"]
    report += ["", "## 2. 서류별 결과"]
    total_err = 0
    for doc in docs:
        src = tdir / doc["template"]
        if not src.exists():
            report.append(f"- {doc['id']} {doc['name']}: ⚠ 템플릿 없음 ({doc['template']})")
            total_err += 1
            continue
        values = dict(proj, 접수번호=fmt("", doc["접수번호"]), 제출일=doc["제출일"], 수신처=fmt("", doc["수신처"]))
        with zipfile.ZipFile(src) as z:
            xml = z.read("Contents/section0.xml").decode("utf-8")
        new_xml, used = fill_xml(xml, values, strip)
        dst = odir / f"{doc['id']}_{doc['name']}_{values['접수번호'] or '번호없음'}.hwpx"
        notes = []
        write_hwpx(src, dst, new_xml, notes)
        errs, blanks = verify(dst, values, used)
        total_err += len(errs)
        state = "✅ 정상" if not errs else "⚠ 확인"
        report.append(f"- {dst.name}: {state} · 채운 항목 {len(used)}개" + (f" · [확인필요] {blanks}" if blanks else ""))
        report += [f"  {m}" for m in errs + notes]
    report += ["", "## 3. 사람이 꼭 할 일", "- 한글에서 열어 표·줄 배치·서명란 확인", "- [참고]·[날짜 순서] 항목은 담당자가 판단"]
    (odir / "검증리포트.txt").write_text("\n".join(report), encoding="utf-8")
    print("\n".join(report))
    sys.exit(1 if total_err else 0)


if __name__ == "__main__":
    main()

  1. [대괄호]만 바꿔 복사·붙여넣기
  2. 새 키 후보 표 확인 후 '추가해줘'
서식을 하나 더 추가할 거야. [새 서식 파일 이름]을 기존 마스터 키에 맞춰 템플릿으로 바꿔줘. - 기존 키로 채울 수 있는 칸은 기존 키 그대로 - 새로 필요한 항목은 '새 키 후보' 표로 먼저 보여주고, 내가 확인한 뒤에 마스터에 추가
새 키 후보 표가 먼저 나오고, 확인 뒤에 템플릿이 만들어집니다.
STEP A-2

오류 고치기 요청

🎯 증상만 정확히 말하면 원인 후보를 나눠 줍니다.
  1. 증상을 [대괄호]에 적기
  2. 확실한 것/추정 구분 확인
한글에서 [파일 이름]을 열었더니 [보이는 증상, 예: 표 칸의 글자가 겹쳐 보임]이야. - 원인 후보를 확실한 것/추정으로 나눠 알려줘 - 원본 템플릿은 건드리지 말고, 고친 결과는 새 이름으로 만들어줘
원본은 그대로 두고 새 이름의 파일이 나옵니다.
STEP A-3

결과 대조 요청

🎯 사람이 6개를 다 열기 전에 핵심 값만 빠르게 대조합니다.
  1. 생성 직후 같은 채팅에 붙여넣기
  2. '불일치' 칸 확인
방금 만든 서류 6개를 다시 읽어서 서류마다 [상호, 설비용량, 허가번호, 제출일]을 표로 뽑아줘. 마스터 값과 다른 칸은 빨간 글씨 대신 '불일치'라고 적어줘.
서류 6개 × 핵심 4항목 표에 '불일치'가 없습니다.
