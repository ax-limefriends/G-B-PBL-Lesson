첨부한 [A_1_전기사업허가신청서] 서식에서 입력 항목을 뽑아 표로 정리해줘.
- 열: 항목명 | 현재 값 | 위치(쪽, 표/본문/서명란)
- 서식에 없는 값은 지어내지 말고 '없음'으로
- 날짜는 YYYY-MM-DD, 설비용량은 kW 숫자로
- 같은 값이 여러 곳에 나오면 위치를 모두 적어줘

프로젝트에 있는 서식 6개를 모두 읽고, 서류마다 반복되는 입력 항목을 '표준 키' 하나로 묶은 매핑표를 만들어줘.
- 열: 표준 키 | 현재 값 | 서류별 항목명(A1~A6) | 형식
- 같은 값이라도 뜻이 다르면(예정일과 실제 완료일) 다른 키로 나눠줘
- 접수번호·제출일·수신처처럼 서류마다 다른 값은 따로 표시
- 표 밖의 본문 문장·서명란에 들어간 값도 빠짐없이
- 서류끼리 날짜가 앞뒤가 안 맞는 곳이 있으면 [확인필요]로 알려줘

방금 매핑표로 마스터 시트(master.xlsx)를 만들어줘.
- 시트: 안내 / 프로젝트(키·값·형식·쓰이는 서류·메모) / 서류별(서류ID·서류명·템플릿 파일·접수번호·제출일·수신처)
- 입력하는 칸만 노란색, '키 열은 바꾸지 말 것' 안내 넣기
- 날짜 칸은 텍스트 서식(엑셀이 숫자로 바꾸지 않게)
- 지금 서식에 있는 값을 예시로 채워줘

서식 6개를 템플릿으로 바꿔줘.
- hwpx 안의 값 글자만 {{표준키}}로 바꾸고 표·글꼴·서식은 그대로
- 표의 값 칸은 왼쪽 항목명을 보고 키를 정해줘(같은 날짜라도 뜻이 다르면 다른 키)
- 머리부(접수번호·신청일), 본문 문장, 서명란, 수신처까지 모두
- 다 바꾼 뒤 예시 값이 하나라도 남았는지 검사해서 서식별 '키 개수'와 '남은 값'을 보고해줘
- 파일 이름: 원래이름_템플릿.hwpx

master.xlsx 값을 템플릿 6개에 채워서 서류를 한 번에 만들어줘.
- 빈 값은 지어내지 말고 [확인필요]로
- 만들기 전 검사: 빈 값, 날짜 형식, 날짜 순서(공사시작≤준공예정, 공사완료≤사용전검사≤사업개시, 허가번호를 적는 서류의 제출일≥허가일)
- 만든 뒤 파일을 다시 열어 {{ }}가 남았는지, 마스터 값이 다 들어갔는지 대조
- 결과: 서류 6개(.hwpx) + 검증리포트.txt

이 서식은 관공서 제출용 법정 서식이야. 템플릿으로 바꾸기 전에 분석만 먼저 해줘.
- 체크박스([ ]), '년 월 일'로 나뉜 칸, 병합된 칸의 위치
- 우리 마스터 키로 채울 수 있는 칸 / 새 키가 필요한 칸(예: 법인등록번호, 전자우편) / 사람이 직접 써야 하는 칸을 나눈 표
- 서식 상단의 근거 법령·서식 번호·개정일을 그대로 적어줘(없으면 '없음')

서식을 하나 더 추가할 거야. [새 서식 파일 이름]을 기존 마스터 키에 맞춰 템플릿으로 바꿔줘.
- 기존 키로 채울 수 있는 칸은 기존 키 그대로
- 새로 필요한 항목은 '새 키 후보' 표로 먼저 보여주고, 내가 확인한 뒤에 마스터에 추가

한글에서 [파일 이름]을 열었더니 [보이는 증상, 예: 표 칸의 글자가 겹쳐 보임]이야.
- 원인 후보를 확실한 것/추정으로 나눠 알려줘
- 원본 템플릿은 건드리지 말고, 고친 결과는 새 이름으로 만들어줘

방금 만든 서류 6개를 다시 읽어서 서류마다 [상호, 설비용량, 허가번호, 제출일]을 표로 뽑아줘.
마스터 값과 다른 칸은 빨간 글씨 대신 '불일치'라고 적어줘.
